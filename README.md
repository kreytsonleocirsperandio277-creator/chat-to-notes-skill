# Chat to Notes｜把零散表达整理成可用笔记

**聊天里不只有消息，还有你没来得及整理的计划、想法和经验。**

把QQ群聊、随手记录和零散文字交给AI，整理成层级清楚、保留具体任务与个人表达的Markdown。暂时无法归类的内容留在文末，方便继续整理。

**试用版 v0.1.0 · 中文优先 · MIT**

Turn scattered chats into structured, reusable Markdown notes. A Chinese-first Agent Skill for organizing relationships, preserving concrete ideas, and keeping uncategorized content for later.

## 先看一个小例子

以下为虚构材料。

**整理前**

> 想接些剪辑单。先做三种风格的案例。  
> 但怕工具突然用不了，交付时得有替代办法。  
> 现在只是想法，还没开始接。  
> 另一个点：旧录音和新拍空镜放一起，做时间变化的对照，还没想好用在哪。

**整理后**

```markdown
# 接下来准备推进的事情
## 剪辑服务与案例准备
想尝试接一些剪辑单，先准备三种风格的案例。
目前还没开始接单；担心主要工具突然不能用，
所以需要考虑交付时的替代办法。

# 暂存与补充：尚未归类的重要内容
想把旧录音与新拍的空镜结合，呈现时间变化。
目前还没决定具体用途，先保留这个构想。
```

## 它具体做什么

- 先分清“大块—主题—局部说明”，再选择标题、粗体和段落；不把总方向和其中的具体事项压成同级。
- 合并承接的消息、拆开混在一起的事情、调整语顺，保留对象、办法、条件、疑问与观点变化。
- 区分原话、转述、后来补充和整理者说明；结合上下文处理图片。
- 重要任务、方向、想法、知识点优先保留。无法归类或不确定该不该删时，放进文末保留区。
- 需要澄清时围绕具体材料提问；修订时保住已经有用的结构和表达。

## 开始使用

将本仓库下载为文件夹，放进你所使用AI工具的技能目录。对于使用本机技能目录的Codex，通常为 `~/.codex/skills/chat-to-notes-skill/`，其中应直接包含 `SKILL.md`。配置了自定义 `CODEX_HOME` 时使用对应的 `skills` 目录。新开聊天后检查该技能是否可用；其他工具请按各自的Agent Skills加载方式配置。

也可以先让能读取本地文件的AI直接阅读本仓库 `SKILL.md`，再提供材料试用。

**复制这句话，附上你的材料：**

> 请使用 $chat-to-notes-skill 整理这些群聊或随手记录。先按内容关系组织层级，保留重要任务、具体想法、条件和个人表达；暂时无法归类的内容放到文末。输出一份可以继续使用的Markdown文档。

有明确用途时，加一句就好，例如“我准备继续推进这些项目”或“我想保留过去的观点变化”。不需要先回答一套固定问卷。

## 输入与辅助脚本

核心编辑由AI完成。脚本负责提取和辅助核对，不调用模型、不登录QQ、不联网。

- TXT、Markdown：按段落准备来源单元。
- JSON：支持消息数组，或带 `messages` 数组的对象；消息包含字符串 `text` 或 `html`。
- QQ HTML：支持含内嵌 `window.__QCE_CHUNK__` 消息数组的QQ Chat Exporter格式。其他版本与外部数据文件格式需要进一步适配。
- 图片与附件：由所用AI工具读取；脚本只保留资源入口，不将未识别图片算作已理解。

脚本需要Python 3.10+，无第三方包依赖。具体命令和去向表格式见[输入与核对方法](references/input-and-coverage.md)。

`finalize_coverage.py` 可以将未登记或无法定位的文字单元补到文末。消息有去向不代表其中每个意思都完整保留，AI仍须检查细节与图文关系。当前试用版不承诺所有材料、模型和导出格式下都零遗漏。
